1. Structural Testing Core Definitions

What is Database Schema Testing?

Instead of checking the data rows inside a table, schema testing checks the structure itself. You are verifying if the tables exist, if columns have the correct names, if they accept the right type of data, and if rules like "cannot be empty" are working properly.

What is information_schema?

This is a built-in, read-only dictionary inside the database. It keeps track of the rules and blueprints for every single table and column you create. As a QA tester, you can query this dictionary to verify if developers built the database correctly according to requirements.
